# CipherBreak

A classical polyalphabetic shift cipher, built properly and then broken three ways: brute force, per-column frequency analysis, and known-plaintext, with measured attack success by ciphertext length and a working AES-GCM replacement.

This is a Vigenere-family cipher, not a model of the WWII Enigma machine.

**Status:** planned. See the product requirements: [docs/prd/CB-01-cipherbreak.md](docs/prd/CB-01-cipherbreak.md).

Rebuilds an earlier script (Enigma-Encryption_-_Decryption) into a tested, measured security project.
